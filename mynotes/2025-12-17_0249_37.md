# CESG Catch-Up Logic

## Overview

CESG (Canada Education Savings Grant) contribution room accumulates over time. Unused room can be carried forward and caught up in future years, but with specific limits.

---

## Core Rules

### 1. Annual Contribution Room Accumulation

- **$2,500** of CESG-eligible contribution room is added **per year** starting from the year the child is born
- This room accumulates regardless of whether an RESP is open
- Room accumulates until the end of the calendar year the child turns **17**

### 2. Carry-Forward Rules

- **Unused contribution room carries forward indefinitely** (until the child turns 17)
- If you contribute less than $2,500 in a year, the unused portion adds to your carry-forward balance
- Maximum lifetime CESG-eligible room = 18 years × $2,500 = **$45,000**

### 3. Annual Catch-Up Limit

- You can only use **$5,000 of contribution room per year** maximum
- This equals: **current year ($2,500) + one catch-up year ($2,500)**
- Therefore, maximum CESG per year = 20% × $5,000 = **$1,000**
- You **cannot** catch up multiple years at once

### 4. CESG Caps

| Cap Type                    | Amount |
| --------------------------- | ------ |
| Annual CESG (no catch-up)   | $500   |
| Annual CESG (with catch-up) | $1,000 |
| Lifetime CESG per child     | $7,200 |

---

## Calculation Formula

```
Available Contribution Room = (Years Since Birth × $2,500) - Total Prior CESG-Eligible Contributions

Usable Room This Year = min(Available Contribution Room, $5,000)

CESG This Year = min(Contribution × 20%, Usable Room × 20%, $1,000, Remaining Lifetime Cap)
```

## Implementation Logic (Pseudocode)

```typescript
interface CESGCalculation {
  contribution: number;
  cesgEarned: number;
  roomUsed: number;
  remainingRoom: number;
  remainingLifetimeCESG: number;
}

function calculateCESG(
  childDOB: Date,
  year: number,
  contribution: number,
  priorTotalRoomUsed: number,
  priorTotalCESG: number
): CESGCalculation {
  const ANNUAL_ROOM = 2500;
  const MAX_ROOM_PER_YEAR = 5000;
  const CESG_RATE = 0.2;
  const MAX_CESG_PER_YEAR = 1000;
  const LIFETIME_CESG_CAP = 7200;

  const birthYear = childDOB.getFullYear();
  const childAge = year - birthYear;

  // Check eligibility (must be 17 or younger at end of year)
  if (childAge > 17) {
    return {
      contribution,
      cesgEarned: 0,
      roomUsed: 0,
      remainingRoom: 0,
      remainingLifetimeCESG: LIFETIME_CESG_CAP - priorTotalCESG,
    };
  }

  // Calculate total accumulated room
  const yearsOfRoom = childAge + 1; // Including birth year
  const totalAccumulatedRoom = yearsOfRoom * ANNUAL_ROOM;

  // Calculate available room (accumulated minus already used)
  const availableRoom = totalAccumulatedRoom - priorTotalRoomUsed;

  // Cap usable room at $5,000 per year
  const usableRoomThisYear = Math.min(availableRoom, MAX_ROOM_PER_YEAR);

  // Calculate CESG-eligible contribution (capped by usable room)
  const cesgEligibleContribution = Math.min(contribution, usableRoomThisYear);

  // Calculate CESG before caps
  let cesgEarned = cesgEligibleContribution * CESG_RATE;

  // Apply annual cap
  cesgEarned = Math.min(cesgEarned, MAX_CESG_PER_YEAR);

  // Apply lifetime cap
  const remainingLifetimeCESG = LIFETIME_CESG_CAP - priorTotalCESG;
  cesgEarned = Math.min(cesgEarned, remainingLifetimeCESG);

  // Calculate room actually used (based on CESG earned)
  const roomUsed = cesgEarned / CESG_RATE;

  return {
    contribution,
    cesgEarned,
    roomUsed,
    remainingRoom: availableRoom - roomUsed,
    remainingLifetimeCESG: remainingLifetimeCESG - cesgEarned,
  };
}
```

---

## Key Points to Remember

1. **Room accumulates from birth**, not from when RESP is opened
2. **Max catch-up is ONE year per year** ($2,500 extra room = $500 extra CESG)
3. **Partial catch-up is possible** — you don't have to use the full $5,000
4. **Contributions over $5,000** in a year still go into the RESP but don't earn CESG that year
5. **Unused room never expires** until the child turns 17 (eligibility cutoff)
6. **CESG lifetime cap ($7,200)** may be reached before all room is used

---

## Edge Cases

### Child turns 17

- Last year to earn CESG is the calendar year they turn 17
- Can still use catch-up room in that final year (up to $5,000 contribution = $1,000 CESG)

### Late RESP opening

- All room from birth is still available
- Can catch up one year at a time with $5,000/year contributions

### Contribution exceeds room

- Example: $10,000 contribution with only $4,000 room available
- Only $4,000 earns CESG ($800)
- Remaining $6,000 goes into RESP but earns no grant that year
- The $6,000 does NOT create future CESG room

### Partial year contributions

- Multiple contributions in a year are summed
- Room is calculated annually, not per contribution
