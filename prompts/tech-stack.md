# Prompt: Tech Stack Planning

## Context

Define the tech stack for a modern, production-ready web application. This prompt helps plan which technologies to use across different layers of the application.

## Tech Stack

### Framework & Language

- **Next.js** (App Router) - React framework with SSR/SSG
- **React** - UI library
- **TypeScript** - Type safety
- **pnpm** - Fast, disk-efficient package manager

### Styling

- **Tailwind CSS** - Utility-first CSS
- **CSS Variables** - Theming support

### UI Components

- **shadcn/ui** - Copy-paste component library (built on Radix UI)
- **Radix UI** - Accessible headless primitives
- **Lucide** - Icon library

### State Management

- **Zustand** - Lightweight global state with persistence

### Forms & Validation

- **React Hook Form** - Performant form handling
- **Zod** - Schema validation

### Data Visualization

- **Recharts** - Charting library

### Utilities

- **date-fns** - Date manipulation
- **next-themes** - Dark/light mode
- **Sonner** - Toast notifications

### Testing

- **Vitest** - Unit testing
- **Playwright** - E2E testing
- **Testing Library** - Component testing

### Code Quality

- **ESLint** - Linting
- **Prettier** - Formatting
- **Husky + lint-staged** - Pre-commit hooks

### Deployment

- **Vercel** - Hosting with Edge runtime support

## Stack Benefits

1. **Full Type Safety** - TypeScript throughout
2. **Accessible by Default** - Radix UI primitives
3. **Great DX** - Hot reload, linting, formatting
4. **Performance** - SSR/SSG, optimized builds
5. **Scalable State** - Zustand with persistence
6. **Validated Forms** - Type-safe form handling
7. **Themeable** - Dark/light mode support
8. **Testable** - Unit and E2E coverage
9. **Production Ready** - SEO, performance optimized
